# Project Documentation Overview

Welcome to the documentation. This repository currently has minimal source code. This docs scaffold is prepared to host comprehensive documentation for all public APIs, functions, and components as the codebase evolves.

- Audience: contributors and users
- Source of truth: code in the repository
- Policy: document all public surfaces with examples and usage notes

Contents:
- API Reference: `docs/api/`
- Components: `docs/components/`
- Examples & Guides: `docs/examples/`
- How to document: `docs/how-to-document.md`

Getting started:
- Add or modify code in the repository
- Run the discovery script to update the API inventory: `scripts/discover-public-apis.sh`
- Fill out docs for each public item using the templates provided
